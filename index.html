🐙 Host on GitHub Pages

This application is 100% serverless and designed to run directly from GitHub Pages without any backend!

  1. Create a new repository on GitHub.com.
  2. Upload this single file as index.html.
  3. Go to Settings → Pages.
  4. Select main branch & click Save.

Once published, share your GitHub Pages URL with anyone. When you both enter the same passphrase, you will connect instantly!
